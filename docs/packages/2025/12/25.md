# 2025/12/25

## 区块链的价值与原理

> WEB2.0 -> 用户没有真正的所有权

> WEB3.0 -> 区块链技术

- 区块链技术利用**密码学**和**去中心化网络**搭建一个公共技术平台
  - **密码学**：所有权控制
  - **去中心化网络**：节点互相验证（要求代码开源），防止作恶

> 实现了： 基于人/组织的信任 -> 基于代码的信任
> Do not trust, verify.

### 去中心化

- 同一个代码（规则）在N个不相关节点上运行
- 节点独立行动：某个节点的数据修改不被其他节点认可
- 没有任何特权节点

### 比特币核心

- 个人私钥控制资产（非对称密码学应用）
- 链式结构，防篡改、好验证
- POW共识：谁先完成计算，谁获得奖励

> 所有权 -> 数字签名。使用私钥控制资产，公钥验证身份，解决确权问题
> 链式结构 -> 账本验证。引入哈希算法，将数据区块链接起来，便于验证数据的正确性，防止篡改
> POW -> PROOF OF WORK。防止双花攻击

- 工作量证明：人为增加记账难度（需解决密码学难题）
- 最快解出密码学难题获得记账权
- 所有人只认同最先延长的区块（最长链）

> 奖励机制 -> 成功记账的矿工可以获得奖励，也是BTC发行过程
> 分叉 -> 等待下一个区块谁先解出

> 共识机制 -> 去中心化网络的节点协作与激励问题通常称为共识问题，解决共识问题的机制（方法）称为共识机制
